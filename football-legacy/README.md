# Football Legacy

Simulador de carreira de futebol no navegador, em português. Comece como promessa desconhecida ou como treinador de um clube pequeno, dispute ligas, copas e continentais, evolua por temporadas infinitas e construa amizades, duplas e trios no **Vestiário**.

- Jogue: `npm install && npm run dev` e abra http://localhost:3000
- Testes: `npm test`
- [ROADMAP.md](ROADMAP.md) · [ARCHITECTURE.md](ARCHITECTURE.md) · [Pesquisa](docs/PESQUISA.md)

Tudo é fictício: clubes, escudos (gerados em SVG), cidades e jogadores. Funciona offline; o modo de IA avançada no Vestiário é opcional e exige uma chave de API no servidor.
