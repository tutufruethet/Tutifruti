# Pesquisa — Copero (referência)

## Limitação
O ambiente de desenvolvimento bloqueou o acesso:
- `curl https://copero.net/pt` → `CONNECT tunnel failed, response 403` (proxy recusou o host).
- Playwright `browser_navigate` → `net::ERR_TUNNEL_CONNECTION_FAILED`.
- Leitura de matérias (7a0.org, minutouno.com, canal26.com, androidphoria.com, cronica.com.mx) → host fora da lista permitida.

Não foi possível ver a interface nem jogar. Nada do Copero foi copiado.

## O que os resultados de busca mostram
- Coleção de minijogos de futebol no navegador, gratuitos, sem download.
- Modo carreira rápida: a carreira inteira de um jogador em cerca de dois minutos.
- O jogador **não controla as partidas**: decide para onde vai e como reage a cada momento decisivo.
- Viralizou na Argentina e no México (meados de 2026).

## O que o Football Legacy faz diferente
| Referência (observado) | Football Legacy |
|---|---|
| Carreira em ~2 minutos | Temporadas completas e infinitas, com ritmo escolhido (dia, semana, próximo compromisso) |
| Decisões em momentos-chave | Decisões narrativas + treino, contratos, mercado, escalação |
| Só jogador | Jogador **e** treinador no mesmo universo (e virar treinador depois de aposentar) |
| Resultado abstrato | Motor de partida minuto a minuto com três modos de acompanhar |
| — | Vestiário com amizades, duplas/trios e conversas por personalidade |
