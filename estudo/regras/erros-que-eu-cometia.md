# Erros que eu cometia

| Erro | Em vez disso |
|---|---|
| Gradiente genérico roxo→azul | Paleta de 3 neutros + 1 acento |
| Cards com sombra e `border-radius` em tudo | Linhas finas, superfícies planas |
| Tudo centralizado | Grid assimétrico, alinhado à esquerda |
| Títulos tímidos (2–3rem) | Display de 8–12vw com convicção |
| Muitas cores e muitos estilos de texto | 2 famílias, 4 estilos |
| Emojis como ícones, glassmorphism sem motivo | Setas tipográficas (↗ ↓), nada decorativo |
| `fade-in` genérico de 0,3s com `ease` | Expo-out de 1s, reveal por linha com máscara |
| Começar a codar sem aprovação do conceito | Duas direções com prévia, o usuário escolhe, depois o código |
| Poste ou árvore cruzando o objeto herói | Corredor de visão limpo em cada pose de câmera |
| `#include` do Three na mesma linha de outro código no shader | Diretiva sempre em linha própria (senão o shader não compila) |
| `font-size` em `cqw` no próprio contêiner | Unidade `cq*` vale para os filhos; ponha `container-type` no pai |
| Medir texto com `scrollWidth` de um bloco | Medir com `Range.getBoundingClientRect()` |
