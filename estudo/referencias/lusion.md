# Lusion

Estúdio de 3D em tempo real. Lusion v3: Site of the Year 2023 + Developer Award no Awwwards.

| Aspecto | O que fazem |
|---|---|
| Papel do 3D | O 3D é o herói e carrega o peso visual. Tipografia e UI são enxutas para não brigar com ele. |
| Tipografia | ~99% do texto numa **única família** (BTS do projeto Oryzo). |
| Paleta | **4 valores** (Oryzo). O site do estúdio aparece no Awwwards como preto/branco. |
| Interação | Cursor reativo e animação de scroll, os destaques citados no v3. |
| Truque barato | Numa versão antiga, a "cena 3D" do hero era um **vídeo renderizado offline** com uma **luz pontual seguindo o cursor**. Comprimiam keyframes e decodificavam o contador de frames no shader. *(fonte antiga)* |
| Stack | three.js nas versões documentadas. Terceiros dizem que hoje é renderer próprio, sem confirmação. |

**Lição:** restrição radical (1 fonte, 4 cores) dá espaço para o 3D brilhar. E nem todo 3D precisa ser tempo real.
