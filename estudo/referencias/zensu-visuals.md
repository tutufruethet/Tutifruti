# Zensu Visuals: vídeo de motion "Built with Claude"

Vídeo de 17 s no TikTok (@zensu.visuals) que mostra um site sendo pedido e montado no chat. Vale como aula de ritmo e de transição, não de layout.

| Ideia | Detalhe |
|---|---|
| **Uma luz só** | Fundo preto, uma faixa de luz laranja difusa (gradiente borrado) que ondula. Toda a peça vive dessa única fonte de cor. |
| Glow como material | Botões em pílula e o card do site com borda clara e brilho externo. O brilho define a forma; não há sombra. |
| Texto que se escreve | "I want a website for…" digitado palavra a palavra, com a última palavra no acento (laranja). |
| Código como textura | Linhas de código passam em perspectiva e desfoque. Não é para ler, é para dar sensação de construção. |
| Card em 3D | O site aparece inclinado em perspectiva e endireita até ficar de frente. Entrada com profundidade, não com fade. |
| Troca de cor = prova | "I want a blue background" e o mesmo card troca de laranja para azul. Mostra o produto reagindo em um corte. |
| Fecho | Volta ao símbolo + "Built with Claude." montado letra a letra. Começa e termina no mesmo ponto. |

**Lição:** fundo escuro + uma luz + glow nas bordas basta para parecer premium. O movimento conta uma história curta (pedido → construção → resultado → mudança) em vez de enfeitar.
