# Frontend Design (Anthropic)

Skill do plugin `frontend-design` em [anthropics/claude-code](https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design). Licença: "todos os direitos reservados" (termos comerciais da Anthropic). **Lido e parafraseado; nada copiado.**

| Ideia | Como aplico |
|---|---|
| Ancorar no assunto | O mundo do assunto (materiais, objetos, vocabulário) é a fonte das escolhas visuais |
| Duas passadas | Plano de tokens (cor, tipo, layout em ASCII, princípios) → teste do genérico → código |
| Sinais de página gerada | Creme + serifa + terracota; quase preto + um acento ácido; cards SaaS; CAIXA ALTA acima de tudo; `01/02/03` sem sequência; `A · B · C`; uma palavra em itálico; `→` em todo botão; mono para rótulo |
| Ousadia num lugar só | Um elemento memorável; o resto quieto (Chanel: tire um acessório) |
| Estrutura é informação | Borda, número, rótulo só se codificam algo do conteúdo |
| Movimento | Um momento orquestrado; movimento que responde à ação é bem-vindo |
| Texto | Ponto de vista de quem usa, voz ativa, o mesmo verbo do botão à confirmação |
| Piso de qualidade | Responsivo, foco visível, reduced motion, contraste, sem anunciar |
| CSS | Cuidado com especificidade que anula padding/margin entre seção e componente |

## Choque com as nossas regras
Várias regras antigas deste estudo são **exatamente** sinais da lista: paleta da [Demo Tutifruti](../demo-tutifruti.md) (`#0b0b0c` + laranja), metadados `(01) — Seção`, rótulos em caixa alta, uma palavra em serifa itálica. Não viraram proibidas: viraram **escolhas que precisam de motivo no briefing**. As notas de regra foram ajustadas.

**Lição:** um estilo de estúdio copiado vira template quando aparece em todo projeto.
