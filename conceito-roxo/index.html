O conceito

Uma interface que se explica em movimento.

Este site traduz a linguagem de um showreel de motion design para a rolagem. Cada cena usa um princípio. Abra um para ver como ele foi aplicado.

01 Movimento

A rolagem controla o avanço e o retorno das cenas. As posições são suavizadas com interpolação, então nada se move de forma linear e mecânica.

02 Tipografia

Duas famílias: uma grotesca para afirmar e uma serifa itálica para dar voz. Os títulos entram por máscara, linha por linha.

03 Ritmo

Cada verbo tem um gesto próprio: as letras se organizam, a palavra acompanha uma linha, o plano se monta em colunas.

04 Profundidade

Fundo, cartão e interface andam em velocidades diferentes. O painel de vidro desfoca o cartão que passa por trás.

05 Transições

O cartão é uma camada única que atravessa as cenas. Ele não troca de lugar por corte: continua o mesmo gesto.
