(04) — Código

Como a ilha funciona

  • Grama: um triângulo por lâmina

    72.900 lâminas no computador, 22.500 no celular. O campo se repete em volta do carro com mod(), então a grama nunca acaba. Técnica lida no código do Bruno Simon.

    // grass.js — vertex shader
vec2 p = mod(aCenter - uCenter + half_, uSize) - half_ + uCenter;
float w = noise(p * .12 + uTime * .55) - .5;
pos.xz += uWind * w * height * tip;   // só a ponta balança

  • Dia e noite em presets

    Quatro atmosferas misturadas por keyframes. A sombra nunca é preta: é a cor do chão do céu, roxa de dia e azul à noite.

    // cycle.js
day:   { sun: '#fff0d6', ground: '#6a4fd6', fogA: '#8fdcff' },
night: { sun: '#7f8cff', ground: '#1e1356', lamp: 3.4 },

  • Física de círculos

    Carro, letras, pinos e caixas são círculos no chão. Quando se tocam, trocam impulso. Pancada forte derruba a letra; depois de 9 segundos ela levanta sozinha.

    // physics.js
const j = -(1 + 0.35) * vn / (ia + ib);
a.vx -= j * ia * nx;  b.vx += j * ib * nx;
b.onHit?.(-vn, nx, nz);   // letra cai na direção do golpe

  • Só a luz brilha

    Bloom com limite 1: só lanternas, faróis, anéis e outdoors passam do limite. De noite as fotos acendem como telas.

    // main.js
new UnrealBloomPass(size, 0.55, 0.45, 1);   // threshold 1
screen.emissiveIntensity = 0.12 + night * 0.75;
